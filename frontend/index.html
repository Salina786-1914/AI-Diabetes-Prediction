PROJECT INFORMATION

About MedAI

AI-based diabetes risk prediction using deep learning.

🧬

AI-Based Diabetes Risk Prediction

MedAI is an academic artificial intelligence project designed to demonstrate how machine learning and deep learning techniques can be applied to healthcare datasets.

The primary model is an Artificial Neural Network developed using TensorFlow/Keras. Patient parameters are standardized before being passed through the trained network.
